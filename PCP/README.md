**Sprint 2 – GoodWe Challenge**  
**ChargeGrid Intelligence – Prova de Conceito e Organização do Projeto**  
---
**Objetivos Principais**  
Evoluir a proposta desenvolvida na Sprint 1  
Desenvolver uma prova de conceito funcional da solução  
Demonstrar a lógica e funcionamento do sistema proposto  
Estruturar e organizar o projeto utilizando metodologia Kanban  
---
*Objetivos Específicos*  
Demonstrar ao menos uma funcionalidade prática da solução  
Apresentar a lógica do sistema e sua aplicação no contexto do ChargeGrid  
Evidenciar conceitos relacionados a:  
gerenciamento inteligente de demanda  
tarifação e pagamento  
interoperabilidade  
inteligência artificial  
Organizar o projeto em um quadro Kanban  
---  
**Tarefa**  
Desenvolver uma prova de conceito funcional da solução proposta na Sprint 1.  
A entrega pode conter:  
protótipo físico  
protótipo digital  
simulação  
interface  
automação  
dashboard  
fluxo lógico  
sistema parcialmente funcional  
Também deve ser criado um quadro Kanban para organização do projeto e tarefas da equipe.  
---
**Entregáveis**  
Enviar APENAS um arquivo .txt contendo:  
Nome e RM dos integrantes  
Link do vídeo no YouTube não listado  
Link do repositório GitHub  
Link do quadro Kanban do projeto  
---  
**Requisitos Obrigatórios**  
O vídeo deve:  
ter no máximo 5 minutos  
demonstrar claramente a solução  
explicar a lógica do projeto  
apresentar o avanço em relação à Sprint 1  
O GitHub deve conter:  
README organizado  
descrição da solução  
arquitetura ou fluxo do sistema  
instruções básicas  
materiais técnicos relevantes  
O quadro Kanban deve:  
estar organizado  
conter tarefas reais do projeto  
evidenciar divisão e evolução das atividades  
possuir acesso público para correção  
---  
**Observações Importantes**  
O foco da Sprint é a evolução prática do projeto  
Simulações devem possuir fundamento técnico  
Links quebrados, privados ou sem permissão de acesso impactam diretamente na nota  
Caso o quadro Kanban não esteja público e acessível, haverá desconto automático de 20% da nota da Sprint

Até 10 pontosOrganização do GitHub e qualidade do README  
Até 10 pontosOrganização do quadro Kanban e gestão do projeto
